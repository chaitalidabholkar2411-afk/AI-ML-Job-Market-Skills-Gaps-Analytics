Project Findings – AI/ML Job Market & Skill Gap Analytics

Project Overview

This project analyzes AI/ML job market data using SQL and MySQL. It focuses on job demand, required technical skills, salary trends, experience levels, and work modes.

Key Findings

1. Job Records: The database contains 100 job records.
2. Skill Demand: SQL, Python, Machine Learning and other technical skills are analyzed to understand employer requirements.
3. Salary Analysis: Salary data is compared across job roles and experience levels.
4. Experience Analysis: Job opportunities are examined based on entry-level and experienced positions.
5. Work Mode Analysis: Remote, Hybrid and Onsite job opportunities are compared.
6. Location Analysis: Job opportunities are analyzed across different locations.

SQL Concepts Used

- SELECT, WHERE and ORDER BY
- GROUP BY and HAVING
- JOIN operations
- Aggregate functions
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- CASE statements

Conclusion

This project demonstrates how SQL can be used to analyze job market data and identify hiring trends, in-demand skills, salary patterns and potential skill gaps.
